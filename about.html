03 / Profile Background & Philosophy

About Me

I am a third-year B.Tech Computer Science student (CMPN A) with a focused interest in frontend web development and user interface design. I enjoy working on the client-facing side of software because it sits at the direct intersection of engineering logic and user experience.

Rather than relying on oversized libraries for basic tasks, I prioritize understanding core web standards—semantic HTML5, flexible CSS layouts, and modern vanilla JavaScript. I care about typography hierarchy, responsive layouts that work on low-spec mobile screens as well as 4K monitors, and interfaces that feel snappy and dependable.

Alongside web fundamentals, my coursework and lab projects have given me solid grounding in algorithms, data structures, and database principles, enabling me to communicate effectively across both frontend and backend domains.
